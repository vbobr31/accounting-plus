# Бухгалтер Плюс

Страница курской бухгалтерской компании, ИНН 4632151121. Дата регистрации — 1 апреля 2011 года. [Источник](https://companies.rbc.ru/id/1114632003001-ooo-buhgalter-plyus/).

## Предпросмотр

Из каталога проекта запустите `python3 -m http.server 8000 --directory docs` и откройте [страницу](http://localhost:8000). Для загрузки модулей JavaScript нужен HTTP.

## GitHub Pages

В репозитории `accounting-plus` откройте **Settings → Pages**, выберите **Deploy from a branch**, затем `main` и `/docs`. Остальные файлы репозитория не входят в публикацию.

## Заявки в Telegram

1. В чате назначения запустите бота или добавьте его в группу, где он может отправлять сообщения. Определите ID этого чата.
2. В каталоге `backend` проверьте `SITE_ORIGIN` в `wrangler.toml`. Укажите origin сайта без пути и завершающего слеша.
3. Разверните Cloudflare Worker через `npx wrangler deploy`. Установите секреты через `npx wrangler secret put TELEGRAM_BOT_TOKEN` и `npx wrangler secret put TELEGRAM_CHAT_ID`. Вводите значения только в интерактивный запрос Wrangler.
4. Перед включением приёма заявок добавьте согласованный текст политики конфиденциальности. В `docs/config.js` укажите публичный адрес Worker с путём `/booking`. После публикации проверьте тестовую заявку и получение сообщения в нужном чате.

Телефон и email оставлены текстовыми заготовками. Настройки cookie хранят отметку о закрытии уведомления в localStorage. Раздел отзывов ведёт на поиск по названию и адресу в Google Картах.
